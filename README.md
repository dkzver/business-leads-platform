# Business Leads Platform

Веб-приложение для управления лидами клининговых компаний и автосервисов.

## Возможности
- Каталог компаний и контактов
- Поиск и фильтрация по стране, городу и специализации
- Статусы контактов и заметки
- Подготовка персональных писем без автоматической отправки
- Защита от повторного добавления компаний

## Статус
Начальная версия проекта. Перед production-развёртыванием необходимо добавить исходный код приложения и настроить постоянное хранилище данных.
